# Support

Use GitHub Issues for reproducible bugs and focused feature requests. Include
the Argo CD version, Trace version, Application source shape, relevant browser
errors, and sanitized API behavior.

Before opening an issue:

1. Read [Installation and troubleshooting](docs/installation.md).
2. Read [Accuracy model and limitations](docs/accuracy.md).
3. Search existing issues.
4. Remove tokens, repository credentials, private URLs, cluster names, and
   Secret values.

This is a community project without a service-level agreement. Security issues
must follow [SECURITY.md](SECURITY.md).
