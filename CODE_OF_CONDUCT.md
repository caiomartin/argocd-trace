# Community Code of Conduct

## Our commitment

We are committed to a respectful, inclusive, and technically constructive
community for everyone, regardless of experience, identity, background, or
location.

## Expected behavior

- Be respectful and assume good intent while evaluating claims with evidence.
- Give actionable feedback about code and ideas, not people.
- Welcome questions and explain unfamiliar project conventions.
- Respect privacy and remove sensitive infrastructure data from examples.
- Accept maintainer decisions about scope while remaining free to disagree
  constructively.

## Unacceptable behavior

Harassment, discrimination, personal attacks, threats, doxxing, sexualized
content, deliberate disruption, and publication of another person's private or
sensitive information are not tolerated.

## Enforcement

Repository maintainers may edit or remove contributions that violate this
code, issue warnings, temporarily restrict participation, or permanently ban a
participant. Enforcement decisions should be proportional, documented
privately when possible, and focused on community safety.

Report conduct concerns privately to a repository maintainer through the
contact methods on their GitHub profile. Do not include confidential details in
a public issue.

## Scope

This code applies in repository spaces and when someone officially represents
the project in public or private community interactions.
